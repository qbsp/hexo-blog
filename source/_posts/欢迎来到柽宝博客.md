你好，欢迎来到 **柽宝博客**！

这是一个用 Hexo 搭建、Fluid 主题渲染的个人博客。以后我会在这里记录生活、分享知识。这篇示例文章用来演示发布流程，也顺便展示一下 Markdown 的基本写法。

## 常用排版示例

### 1. 段落与强调

普通段落直接用文字即可。**加粗**、*斜体*、`行内代码` 都可以直接写。

### 2. 列表

- 无序列表项一
- 无序列表项二
  - 嵌套子项

1. 有序列表项一
2. 有序列表项二

### 3. 引用

> 记录思考，分享热爱。

### 4. 代码块

```bash
hexo new "文章标题"
git add .
git commit -m "发布新文章"
git push
```

### 5. 链接与图片

- 链接写法：`[Hexo 官网](https://hexo.io)`
- 图片写法：`![](https://example.com/image.png)`

## 发布流程回顾

写好后只需要三条命令即可上线：

```bash
git add .
git commit -m "发布新文章"
git push
```

推送到 GitHub 后，Cloudflare Pages 会自动构建部署，稍等一两分钟就能在 https://chengbao.dpdns.org 上看到新文章。
